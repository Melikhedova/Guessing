# Игра УАГАДАЙКА

Написана на **GOland**.

Весь игровой процесс проходит непосредственно в терминале (консоли), а интерфейс дополнен цветным выводом для более приятного визуального восприятия.

### 🛠️ Используемые пакеты: 
* `fmt` — ввод и вывод данных в консоль.
* `bufio` & `strings` — чтение строк и обработка пользовательского ввода.
* `math` & `math/rand` — генерация случайных чисел и математические операции.
* `time` — работа со временем.
* `os` — взаимодействие с операционной системой (работа с файлами).
* `encoding/json` — сохранение истории игры в формате JSON.
* `regexp` — валидация ввода пользователя с помощью регулярных выражений.
* `strconv` — конвертация строк в числа и обратно.

## 🚀 Как развернуть и запустить проект

Для запуска игры на вашем компьютере должен быть установлен **Go** (версии 1.16 или выше).

### 1. Клонирование репозитория
Склонируйте проект к себе на локальный компьютер:
```bash
git clone https://github.com/Melikhedova/Guessing.git
cd Guessing
```

### 2. Инициализация модуля (если проект создается с нуля)
Если в проекте еще нет файла `go.mod`, инициализируйте его:
```bash
go mod init ugadaika
```

### 3. Установка зависимостей
Загрузите внешний пакет `fatih/color`, используемый в проекте:
```bash
go mod tidy
```

### 4. Запуск игры
Для быстрого запуска игры без сборки исполняемого файла выполните:
```bash
go run main.go
```

### 5. Сборка (опционально)
Если вы хотите скомпилировать проект в готовый исполняемый файл:
```bash
go build -o ugadaika
./ugadaika
```
